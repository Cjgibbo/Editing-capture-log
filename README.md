# Editing Capture Log

Capture log for the Sturm & Róisín Publishing manuscript editing pipeline. Auto-pushed from Claude project threads.

## Folder Structure

- `captures/prompt/` — Prompts or instructions that produced notably better results
- `captures/parser/` — Parser rules added, modified, or abandoned
- `captures/decision/` — Scope or process decisions
- `captures/edge-case/` — Edge cases encountered and how they were resolved
- `captures/format/` — Formatting or output patterns to replicate
- `captures/process/` — Process workflow captures
