# Five instruction gaps flagged before Tier 3 work could start.

**Tier:** 3
**Destination:** system-prompt

## Detail

1.	Tier 3 has no numbered workflow (Tiers 1 and 2 do). Implied steps: receive files → confirm plan → proof → full assembly → briefing. Not codified.

	2.	Tier 3 briefing contents are not defined. The general rule says every pass produces a briefing, but Tiers 1 and 2 spell out what goes in theirs. Tier 3 does not.

	3.	Non-Direct Tier 3 and content issues: instructions explicitly say Tier 3 Direct doesn't flag content. They're silent on what to do when Tier 3 follows Tier 1 and a content issue is spotted during formatting.

	4.	Add-on options (ornaments, running headers, header rules) are not in the Tier 3 intake questionnaire. Memory says they're presented after base template selection, but the actual questionnaire doesn't include them.

	5.	Image handling workflow is undefined in the instructions — no guidance on who decides placement, how images are provided, or format requirements.
