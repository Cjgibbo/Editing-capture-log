# The Stride template's Tier 3 font was changed mid-engagement with client approval — this is a valid workflow for client-specific adjustments within a preset template.

**Tier:** 3
**Destination:** system-prompt

## Detail

The Stride template spec defines EB Garamond as the body font. For this engagement, the font was changed to Crimson Pro based on the manuscript's number-heavy content. Chris approved after seeing a side-by-side comparison. The template spec in memory was updated. This establishes that template presets are starting points — per-engagement font substitutions within the same family (serif for serif, matching weight/style) are valid when the manuscript content warrants it, with client approval.
