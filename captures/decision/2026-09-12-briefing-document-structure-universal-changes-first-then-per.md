# Briefing document structure — universal changes first, then per-chapter, then outstanding items.

**Tier:** general
**Destination:** build-log

## Detail

The Tier 2 briefing organized content as:

	1.	Universal changes applied to all chapters (voice conversion, label removal, bullet-to-prose, ending variation, Tier 1 cleanup) — documented once, not repeated per chapter

	2.	Ch 1–6 summary (structural work from prior thread, pulled from handoff)

	3.	Ch 7–11 individual sections with structural changes, factual corrections, and voice conversion details

	4.	Outstanding items (title, dedication, diagrams)

	5.	Final word count table

This structure avoids repeating "opening labels removed" eleven times. For the author, the universal section establishes what happened everywhere, then the per-chapter sections only document what's unique to that chapter. This should be the standard briefing format going forward.
