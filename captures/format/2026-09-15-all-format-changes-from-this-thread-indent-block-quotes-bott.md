# All format changes from this thread (indent, block quotes, bottom margin, heading hierarchy) apply to ALL style templates, not just Stride.

**Tier:** 3
**Destination:** style-reference

## Detail

Chris confirmed each of these as global rules:

	•	First-line indent 0.15" (was 0.25")

	•	Block quote indent 0.35" both sides (was 0.5"/0.25")

	•	Bottom margin safe zone 0.875" (was 0.625")

	•	Heading hierarchy with visual differentiation between section heads and sub-heads

These need to be propagated to Heritage, Chronicle, Meridian, Blackletter, and Vespers template specs in project memory.
