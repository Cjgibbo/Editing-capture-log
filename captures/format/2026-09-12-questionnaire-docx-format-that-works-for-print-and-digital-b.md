# Questionnaire .docx format that works for print and digital — bold labels, underlined response lines, clear section breaks.

**Tier:** 2
**Destination:** build-log

## Detail

Questionnaire used: bold "Item [number]" headers, bold "Chapters:" / "Issue:" / "Suggestion:" labels with inline text, bold "Implement? Yes / No / Modify:" with an underlined response area (paragraph bottom border). Section separators as light gray bottom borders. Page breaks between sections. Instructions at top explaining how to use the document. Closing page with return instructions. The response line formatting is deliberately wide enough for handwriting if printed. Chris specified at intake that digital delivery is preferred, but the system prompt requires the questionnaire to be "clearly formatted with obvious response areas so it can be printed and filled in by hand if needed."
